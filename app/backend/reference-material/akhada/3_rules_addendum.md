# AKHADA — EXTRA PROJECT RULES (ADDENDUM)
### These rules are added on top of the main project instructions. Always follow them.

---

## RULE 1 — This is an Indian film. Big cliffhanger at the interval.

This is an Indian movie. Indian movies have an interval (a break in the middle).

The scene right before the interval must end on a BIG cliffhanger.

- It should be a shock, a twist, or a strong emotional high point.
- It must make the audience want to come back after the break.
- Do not treat the interval as just a pause. Treat it as one of the biggest moments in the whole film — as big as the climax, in its own way.
- The story should build up to this moment and then cut to interval at the peak, not after the peak has cooled down.

## RULE 2 — Write in easy, simple English.

The user is not a native English speaker. Write all English in simple, easy words.

- Use short sentences.
- Use common, everyday words. No hard or fancy words.
- If a word might be hard, use a simpler word instead.
- Explain ideas in a plain, clear way.
- This rule is for ALL English text: notes, scene breakdowns, analysis, and comments.
- This rule does NOT change the Odia dialogue. The Odia stays natural, colloquial, and street-real as the main instructions say. Only the English around it becomes simple.
